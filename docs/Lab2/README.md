# Лабораторная работа 2

## Решающий пень

В работе реализована модель решающего пня — дерева решений глубины один.
Модель поддерживает два критерия:

- регрессионный критерий на основе суммы квадратов сумм откликов в листьях;
- классификационный критерий на основе индекса Джини.

Модель реализует общий интерфейс `IModel` с методами `fit` и `predict`.
После обучения доступны выбранные признак и порог через методы
`split_feature()` и `split_threshold()`.

## Быстрый поиск разбиения

Для каждого признака сортируются индексы объектов по значению признака.
Затем объекты последовательно переносятся из правой части в левую. Агрегаты
критерия обновляются за `O(1)`:

- для регрессии хранятся сумма откликов и размер левой части;
- для классификации хранятся квадраты счётчиков классов.

Пороги между одинаковыми соседними значениями не рассматриваются. Для
допустимого разбиения используется середина между соседними различными
значениями, а размер листьев ограничивается параметром `min_samples_leaf`.

Сложность быстрого алгоритма составляет `O(d * n log n)`, где `d` — число
признаков, а `n` — число объектов. Дополнительная память — `O(n)`.

## Наивная реализация

Наивный алгоритм находится только в
[`tests/decision_stump_tests.cpp`](../../tests/decision_stump_tests.cpp).
Для каждого признака и каждого значения признака он полностью проходит
выборку, раскладывает объекты по листьям и заново вычисляет критерий. Поэтому
его сложность составляет `O(d * n^2)`.

Выигрыш быстрого алгоритма достигается тем, что сортировка выполняется один
раз для признака, а при переходе к следующему порогу меняется только один
объект. Полный пересчёт критерия для каждого порога больше не нужен.

## Предобработка и запуск

В текстовом интерфейсе датасет делится на обучающую и тестовую части. Target
`Class/ASD` кодируется числовыми метками, после чего выбирается `Gini`.
Пункт меню `Train decision stump and predict test data` обучает пень, выводит
признак и порог и позволяет просматривать случайные предсказания.

Параметр размера листа задаётся аргументом:

```text
--min_sample_leaf 10
```

## Тесты и измерение времени

Тесты запускаются через CTest:

```text
cmake --build build
ctest --test-dir build --output-on-failure
```

`decision_stump_tests` дополнительно обучает быструю и наивную реализации на
исходном датасете `data/Autism-Adult-Data.csv`, выводит среднее время трёх
запусков и ускорение быстрого алгоритма.

Проверяются выбор разбиения, регрессия, классификация, предсказания,
`min_samples_leaf`, константные признаки, дубликаты значений и обязательные
исключения.
