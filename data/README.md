# Autism Screening Adult

## Источник

В лабораторной работе используется датасет **Autism Screening Adult** из
репозитория UCI Machine Learning Repository:

- страница датасета: <https://archive.ics.uci.edu/dataset/426/autism+screening+adult>;
- архив для загрузки: <https://archive.ics.uci.edu/static/public/426/autism+screening+adult.zip>;
- файл, используемый программой: `Autism-Adult-Data.csv`.

Датасет предназначен для классификации результатов скрининга расстройств
аутистического спектра (ASD) у взрослых. На странице UCI указана лицензия
**CC BY 4.0**; при распространении датасета необходимо сохранять ссылку на
источник и указание авторства.

Исходный файл содержит **704 объекта** и **21 признак**. Целевой признак —
`Class/ASD`: значение `YES` означает положительный результат скрининга, а
`NO` — отрицательный.

## Формат исходного файла

- формат: CSV;
- разделитель: запятая (`,`); запятые внутри отдельных значений заключены в
  одинарные кавычки;
- первая строка содержит имена столбцов;
- кодировка: UTF-8;
- строка пропущенного значения: `?`.

После загрузки `?` представляется как отсутствующее значение
(`std::nullopt`), а не как специальное числовое значение или пустая строка.

Имена столбцов исходного файла:

```text
A1_Score, A2_Score, A3_Score, A4_Score, A5_Score,
A6_Score, A7_Score, A8_Score, A9_Score, A10_Score,
age, gender, ethnicity, jundice, austim, contry_of_res,
used_app_before, result, age_desc, relation, Class/ASD
```

В исходных именах сохранены опечатки `jundice`, `austim` и `contry_of_res`,
чтобы программа соответствовала фактическому заголовку CSV.

## Типы признаков

Тип определяется автоматически по значениям столбца, без списка имён столбцов
в коде:

1. пропуски `?` игнорируются;
2. если каждое оставшееся значение разбирается как конечное число с плавающей
   точкой, столбец считается числовым;
3. иначе столбец считается категориальным.

По этому правилу `A1_Score`–`A10_Score`, `age` и `result` являются числовыми
признаками. Остальные столбцы, включая целевой `Class/ASD`, являются
категориальными. Бинарные признаки ответов на вопросы намеренно остаются
числовыми: их значения `0` и `1` имеют количественный смысл.
