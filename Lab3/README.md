# Работа 3. Новая модель и срезы матрицы

Выберите один вариант работы. Каждый файл объединяет объяснения и полное
условие; выполнять оба варианта не нужно.

| Вариант | Задача | Условие |
|---|---|---|
| Основной | Регрессор и классификатор Надарая — Уотсона: плавное взвешивание обучающих объектов по расстоянию | [lab_3_standard.md](lab_3_standard.md) |
| Со звёздочкой | Дерево CART: развитие решающего пня из работы 2, рекурсивное построение и владение узлами | [lab_3_star.md](lab_3_star.md) |

В обоих треках добавляются `MatrixSlice` для строк и столбцов при любом layout,
интерфейсы `IRegressor` и `IClassifier`, вероятности классов и метод `classes()`.
Разбираются константность, ref-квалификаторы, время жизни срезов и обязанности
конструктора, `fit` и `predict`.

Основной вариант продолжает kNN, сложный — решающий пень. Данные и разбиение
на обучение и тест сохраняются из предыдущих работ.

**С агентом:** можно писать тесты и генерировать отклики для второй постановки,
которой нет в датасете. Новые алгоритмы, интерфейсы и срезы реализуются
самостоятельно; ожидаемые ответы тестов нужно понимать и проверять.
