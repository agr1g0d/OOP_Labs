# Работа 4. Ансамбли и параллельные вычисления

Выберите один вариант работы, продолжающий ваш трек работы 3. Каждый файл
содержит объяснения и полное условие; выполнять оба варианта не нужно.

| Вариант | Задача | Условие |
|---|---|---|
| Основной | Бэггинг kNN/NW: случайные выборки объектов и признаков, адаптеры, фабрики и усреднение ответов | [lab_4_standard.md](lab_4_standard.md) |
| Со звёздочкой | Random forest по базовой схеме sklearn: bootstrap, доработка CART и выбор признаков в каждом узле | [lab_4_star.md](lab_4_star.md) |

Ансамбль используется через тот же интерфейс, что и отдельная модель.
Регрессоры усредняют предсказания, классификаторы — вероятности классов.
Каждая модель или дерево получает собственный seed, воспроизводимо назначенный
из общего `random_state`.

В обоих треках независимые задачи обучения и предсказания распараллеливаются
**только через `std::jthread`**, с ограничением числа потоков. Нужно проверить
совпадение результатов последовательного и параллельного запуска и измерить время.
Ускорение и улучшение точности не гарантируются.

**С агентом:** разрешены код распараллеливания и его отладка; итоговую реализацию
нужно уметь объяснить. Композиция, выборки, seed и объединение ответов —
самостоятельная часть. Сверка леса со sklearn необязательна и тоже может
выполняться с помощью агента.
